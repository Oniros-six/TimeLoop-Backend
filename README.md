# 🕒 TimeLoop Backend
Backend system for the TimeLoop appointment scheduling app, built with NestJS, Prisma ORM, and PostgreSQL.

## 🚀 Main Features
- Appointment management by service and business.
- Multi-user and multi-business support.
- Role-based access control with permissions.
- Weekly schedules and one-time override support.
- Audit logging of system activity.
- Strict business logic validations.
- Scalable and modular architecture.

## 📦 Tech Stack
- **NestJS** – Modular Node.js framework
- **Prisma** – Modern, type-safe ORM
- **PostgreSQL** – Relational database engine
- **TypeScript** – Static typing
